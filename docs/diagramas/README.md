# Diagramas del proyecto

Esta carpeta contiene diagramas editables de draw.io para documentar el proyecto de base de datos documental de Cafe Central.

## Archivos

- `modelo-documental.drawio`: muestra las colecciones principales de la base de datos y como se relacionan los documentos.
- `flujo-pedidos.drawio`: muestra el flujo general para registrar clientes, consultar productos, crear pedidos y realizar consultas.

## Como abrirlos

1. Entrar a https://app.diagrams.net/.
2. Seleccionar **Archivo > Abrir desde > Dispositivo**.
3. Elegir el archivo `.drawio`.
4. Editar el diagrama si es necesario.
5. Exportar como PNG o PDF si la profesora solicita una evidencia visual.

## Diagramas recomendados para la entrega

- Modelo documental de la base de datos.
- Flujo principal de creacion de pedidos.
- Consultas principales del sistema.

Estos diagramas ayudan a explicar por que el proyecto usa una base de datos orientada a documentos y como se organizan los datos de clientes, productos y pedidos.
